# BUG-003 — Product Details Display Corrupted Information

## Environment

- Application: SauceDemo
- User: `problem_user`
- Browser: Google Chrome
- Area: Product Details
- Test Type: Manual Testing

## Severity

High

## Priority

High

## Preconditions

User is logged in as `problem_user` and is on the Products page.

## Steps to Reproduce

1. Open SauceDemo.
2. Log in using `problem_user / secret_sauce`.
3. Navigate to the Products page.
4. Select a product and open its product details page.
5. Observe the product name, description and price.

## Expected Result

The product details page should display the correct product name, image, description and price for the selected product.

## Actual Result

The product details page displays corrupted/incorrect information, including an `ITEM NOT FOUND` message and an invalid price value (`$√-1`) instead of valid product details.

## Impact

Incorrect product information can prevent users from understanding the product and may lead to incorrect purchasing decisions.
