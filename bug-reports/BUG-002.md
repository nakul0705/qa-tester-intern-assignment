# BUG-002 — Product Sorting Dropdown Does Not Accept Selection

## Environment

- Application: SauceDemo
- User: `problem_user`
- Browser: Google Chrome
- Area: Products Page
- Test Type: Manual Testing

## Severity

Medium

## Priority

High

## Preconditions

User is logged in as `problem_user` and is on the Products page.

## Steps to Reproduce

1. Open SauceDemo.
2. Log in using `problem_user / secret_sauce`.
3. Navigate to the Products page.
4. Locate the product sorting dropdown.
5. Click the sorting dropdown.
6. Attempt to select a different sorting option, such as `Name (Z to A)`.

## Expected Result

The selected sorting option should be accepted and displayed in the dropdown, and the product list should be reordered accordingly.

## Actual Result

The sorting dropdown does not accept the selected option and remains on the existing selection.

## Impact

Users cannot sort products according to their preferred order, reducing the usability of the product listing.
