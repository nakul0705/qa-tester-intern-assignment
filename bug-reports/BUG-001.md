# BUG-001 — Product Images Do Not Match Corresponding Products

## Environment

- Application: SauceDemo
- User: `problem_user`
- Browser: Google Chrome
- Area: Products Page
- Test Type: Manual Testing

## Severity

Medium

## Priority

High

## Preconditions

User is logged in as `problem_user` and is on the Products page.

## Steps to Reproduce

1. Open SauceDemo.
2. Log in using `problem_user / secret_sauce`.
3. Navigate to the Products page.
4. Observe the product cards.
5. Compare each product image with its corresponding product name.

## Expected Result

Each product should display its correct corresponding product image.

## Actual Result

Multiple products display the same dog image instead of their corresponding product images.

## Impact

Incorrect product images can mislead users about the products they are viewing and negatively affect product identification and purchasing decisions.

See the corresponding screenshot attached to GitHub Issue #1.
